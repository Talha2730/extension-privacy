# Urdu Phonetic Writer — Support

For help with Urdu typing, copy/paste, saving drafts, or extension errors, use the [GitHub Issues page](https://github.com/Talha2730/extension-privacy/issues) or review the instructions below.

## Basic troubleshooting
- Pin the extension to the toolbar and click its icon to open the editor.
- If paste does not work, first copy some text, reopen the extension, and click Paste.
- Saved drafts remain in this browser profile's local storage; clearing extension data may delete drafts.

## Privacy
The extension stores typed drafts locally and only accesses the clipboard when you click Copy or Paste. It does not execute remote code or upload clipboard text.
