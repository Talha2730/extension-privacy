What is 2FA Authenticator?

2FA Authenticator is a Chrome extension for users who need TOTP-based two-factor authentication codes while browsing. It is designed for services that support standard authenticator codes and makes it convenient to access verification codes from Chrome.

Two-factor authentication adds an additional verification step to account sign-in. When a compatible website asks for a TOTP or authenticator code, the extension can generate the current code for an account you have configured.

Frequently asked questions

Does it generate TOTP codes?

Yes. The extension is designed to generate time-based one-time passwords for compatible services using standard TOTP authentication.

Can I use QR codes to add accounts?

The extension supports QR-code-based account setup where supported by the service and extension configuration.
