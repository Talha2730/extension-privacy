# Urdu Phonetic Writer & Copy-Paste

A Chrome extension to type Urdu with an English phonetic keyboard, use an on-screen keyboard, copy and paste text, and save drafts locally in your browser.

## How to use
1. Install the extension from the Chrome Web Store and pin it.
2. Open its popup and type Urdu using phonetic keys.
3. Use Copy to copy typed text or Paste to insert clipboard text.

## Privacy
Drafts are stored locally in Chrome. The extension does not send typed or clipboard text to a server and does not execute remote code.
